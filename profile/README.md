## 🧰 Troubleshooting

### Trainer does not start

Check that:

- The game is installed correctly
- The trainer version supports your game build
- Windows security software has not blocked required files
- The trainer is started with the required permissions
- Conflicting modifications are disabled

### Features do not work

Feature availability can depend on the game version and trainer build.

Try:

1. Closing the game.
2. Restarting the trainer.
3. Checking the supported game version.
4. Testing without other gameplay modifications.
5. Starting a new Story Mode session.

### Game crashes after installing a modification

Remove recently added modifications and test the game again.

Keeping a backup of the original game configuration and save files can make troubleshooting easier.
